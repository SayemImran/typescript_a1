# Problem Solving with TypeScript & OOP

## Overview
This repository contains my solutions for the TypeScript assignment covering Modules 1, 2 and 3. The work includes eight problem-solving tasks and two blog posts.

The solutions are in `solutions.ts`. They use basic types, optional, default and rest parameters, readonly tuples, interfaces, type narrowing, generics, Promises, and OOP with access modifiers and inheritance.
